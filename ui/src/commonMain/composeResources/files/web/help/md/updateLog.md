## 2026/10/19 - 11/02

朗读跨章自动续读全端打通，读到章末会等新章节加载后接着读，不再无声停住；滚动模式推进不再裁掉当前段，长段实时翻页。发现与搜索的参数行长按可弹出带搜索框的选择弹窗，多选标签恢复原版整行勾选；分享进来的普通文字按搜索词处理，不再被拉去联网后报错；未设书籍保存位置时备份自动改传网盘，不再空报已备份。播放、阅读等页面再次进入时复用原页面，从通知点进来不再叠出一层新页。

书源脚本支持上传二进制请求体、按原始字节计算摘要与构造替换响应，桌面端补齐国密算法；关掉书源登录窗口时已填的账号不再丢。修 iOS/鸿蒙所有书源搜不到结果、有插图的书点离线缓存没反应、EPUB 章节锚点失效把下一章并进上一章、桌面备份在安卓端恢复失败、正式包插件加载即崩、Windows 从网络共享拖书源导入报路径不存在；导入与文件选择的等待可随时取消，关闭页面不再留卡住的请求。移除了无权限保护的对外数据接口，第三方工具统一改走 Web 服务。

## 2026/10/16 - 10/19

播放页新增沉浸歌词与逐字动效，支持 QQ 音乐 QRC 逐字歌词；歌词行滚动带缓动、当前行入场带辉光，播放时背景与边缘光效随音频起伏，点顶栏标题可进书籍详情。修复逐字歌词的译文与偏移丢失、双语歌词译文整段消失、暂停后光效冻在最后一帧。

书源脚本在 iOS/鸿蒙端补齐节点与作用域接口，请求头改写即时生效，对称解密支持二进制字节入参；本地书与字体可直接选文件导入，返回手势跟手可关。修复安卓 12 以下背景模糊失效、搜索列表拖动时不收键盘、自动过 Cloudflare 挑战过早放弃，以及 iOS/鸿蒙非法链接闪退。

## 2026/10/07 - 10/16

书源脚本新增压缩数据解压，书源可设置图标与列表下一页地址规则；内置在线朗读源换成实测可用的免登录接口，读完末章自动停止，起播失败不再卡住会话。

视频新增画面缩放与新倍速档位，阅读新增段首标点悬挂，批注支持就地点按输入；备份与导出统一落到书籍保存位置，半屏弹层可上拉全屏，跟随系统的深浅色切换即时生效。修复多处列表重复与旧系统启动闪退，文件写入改为整份落盘，中断不再损坏缓存与本地书籍。
