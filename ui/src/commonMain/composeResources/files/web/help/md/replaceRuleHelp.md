# 替换管理界面帮助

* 替换规则是用来替换正文/标题内容的一种规则
  * 右上角菜单：新建替换、本地导入、网络导入、帮助
  * 右上角分组菜单：分组管理、未分组、各分组
  * 长按拖动排序
  * 右下角批量菜单（针对选择的规则）：启用所选、禁用所选、置顶所选、置底所选、导出所选
* 规则字段
  * `name` / `group` 规则名称与分组
  * `pattern` 查找内容；`replacement` 替换为
  * `isRegex` 开启时按正则替换，关闭时按普通文本替换；`timeoutMillisecond` 正则替换的超时时间（毫秒，默认3000）
  * `scope` 作用范围，填书名或书源地址的子串，留空表示全部
  * `excludeScope` 排除范围，书名或书源地址命中即本条不生效（优先于 `scope`）
  * `scopeTitle` / `scopeContent` 分别作用于章节标题 / 正文
