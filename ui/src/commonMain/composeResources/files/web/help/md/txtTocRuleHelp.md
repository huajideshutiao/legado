## Txt目录正则说明

### 菜单区

- 新建目录规则，当Legado自带的规则不能够满足需求时，用户可根据自己的情况自定义目录规则
- 本地导入 / 网络导入 为了方便异步调试以及用户导入他人的目录规则，Legado增加目录规则的导入功能。点击 网络导入 的输入框，可以通过内置的链接导入在线规则。（在线规则优先比内置的规则更加激进，但适配了更多类型的标题格式，用户需根据自己的情况选择是否导入）
- 导入默认规则 在旧版本中，Legado自带的规则不会随着软件的更新而更新。用户需要使用最新规则或对自带规则修改后需要重置时，可点击 导入默认规则。**注意：导入默认规则不会重置用户自定义的规则，但如果您对自带的规则进行了修改，则修改的规则会被重置为默认规则。**
- 帮助 查看本说明

### 操作区

- 每一行：左侧复选框用于批量选择；名称下方是该规则的示例文本；右侧开关点亮表示该规则参与自动识别目录（针对**所有TXT书籍生效**），编辑按钮修改当前规则，更多菜单可置顶/置底/删除当前规则（默认的规则删除后可点击 导入默认规则 按钮恢复）
- 长按拖动排序
- 分章时所有启用的规则都会对目录做一次试算，取匹配到的章节标题数最多的那条规则来分章（不是按顺序依次套用）
- 底部批量菜单（针对选择的规则）：启用所选、禁用所选、导出所选
- 拆分超长章节不在本界面，在本地TXT书籍的目录界面更多菜单（详情页菜单也有）里按书籍设置；开启后单章超过约100KB（UTF-8中文约3.4万字）会自动分为多章
